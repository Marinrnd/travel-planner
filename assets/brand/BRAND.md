# The Slow Atlas — Brand Guide

> Plan every trip for the rest of your life.

## Logo files (`dist/brand/`)
| File | Use |
|------|-----|
| `logo-primary.png` | Stacked logo, transparent — general use, watermarks |
| `logo-horizontal.png` | Horizontal lockup, transparent — headers, invoices |
| `avatar-cream.png` | 600×600 — Etsy shop icon (light) |
| `avatar-terracotta.png` | 600×600 — Etsy shop icon (bold/alt) |
| `banner.png` | 1680×420 — Etsy shop banner |
| `emblem.svg` | The globe mark alone (vector, recolorable) |

Regenerate the PNGs from `assets/brand/logo.html` (open and screenshot, or use
the Playwright snippet used to build them).

## Colour palette
| Name | Hex | Use |
|------|-----|-----|
| Ink | `#2E2A24` | Wordmark, body text |
| Terracotta | `#B9603F` | Emblem, accents, CTAs |
| Sage | `#7C8A6B` | Secondary accent ("The", labels) |
| Dusty blue | `#5B788A` | Tertiary accent |
| Cream | `#FAF7F1` | Backgrounds / paper |
| Taupe | `#8C8478` | Muted text, taglines |

## Typography
- **Italiana** — display wordmark & headings
- **Lora** (incl. *italic*) — editorial accents, taglines
- **Outfit** — labels, body, UI (use Bold + wide letter-spacing for small caps)

All three are SIL OFL licensed (free for commercial use); files in `assets/fonts/`.

## The emblem
A line-drawn globe (atlas) — calm, minimal, and legible even at favicon size.
Keep clear space around it equal to the height of one latitude band. Don't
recolour it outside the palette above.
