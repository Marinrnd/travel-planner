# Thailand — The Guide · Image Manifest (Shot List)

A ready-to-use sourcing list for the photo-rich layout. Every image needed,
with an exact **royalty-free search query**, a **source**, a **licence note**,
its **placement** and a **caption idea**. Drop these into Canva/InDesign frames.

**Licences — quick rules**
- **Unsplash** / **Pexels** / **Pixabay** → free for commercial use, no attribution required (credit appreciated). ✅ Safe to sell.
- **Wikimedia Commons** → check each file: **Public Domain** ✅ safe; **CC-BY** ✅ but you must credit; **CC-BY-SA** ⚠️ avoid (share-alike).
- Never use a Google Images result directly — trace it to a licensed source first.
- Keep a credits line per image in a final "Photography" page (good practice even when not required).

**Placement key:** `FB` = full-bleed full page · `SPREAD` = double-page · `½` = half page · `SPOT` = small inset · `COVER`.

### Sourcing workflow (15 minutes)
1. Open **unsplash.com** and **pexels.com**.
2. Paste each query, pick the highest-resolution **horizontal** shot for FB/SPREAD, **vertical** for ½.
3. Download the largest size; rename `01-cover.jpg`, `04-intro-spread.jpg`, etc. (match the # column).
4. Keep a tiny `credits.txt` (photographer + source) — good practice.
5. Drop them into the matching frames in your Canva/InDesign template (see the Layout Guide).
